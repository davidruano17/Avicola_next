# Resolución de problemas

| Problema | Acción |
|---|---|
| No inicia sesión | Revise correo y contraseña; confirme que la cuenta esté activa |
| Sesión vencida | Inicie sesión nuevamente |
| No carga el inicio | Verifique conexión y dirección del servidor |
| Error al guardar | Revise campos obligatorios y valores negativos o inválidos |
| Registro pendiente | Espere la reconexión y confirme la sincronización |
| Falta un registro | Revise filtros, galpón y rango de fechas |
| Usuario sin permiso | Solicite al administrador la asignación del rol |
| Error 500 | Capture la hora y la acción realizada; reporte el incidente |

## Solicitar soporte

Antes de solicitar soporte, tenga disponible:

- Nombre del usuario.
- Rol.
- Fecha y hora del problema.
- Módulo y acción realizada.
- Mensaje mostrado.
- Navegador utilizado.
- Captura de pantalla si está autorizada.

!!! danger "DATOS SENSIBLES"
    No incluya contraseñas, datos personales innecesarios ni credenciales en el mensaje de soporte.
