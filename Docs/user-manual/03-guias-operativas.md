# Guías operativas

## Consultar el inicio

En **Inicio** revise los indicadores consolidados de aves, producción, mortalidad, morbilidad y movimientos financieros.

Use los filtros disponibles y vuelva a cargar el módulo si necesita actualizar la información.

## Gestionar galpones de aves

1. Abra **Galpones de aves**.
2. Seleccione **Agregar** o **Nuevo galpón**.
3. Complete el formulario con número, fechas, peso, cantidad de aves, semana de vida, línea, responsable y observaciones.
4. Revise los datos.
5. Confirme el registro.

Para consultar o editar:

1. Localice el galpón en la tabla.
2. Seleccione **Ver** o **Editar**.
3. Modifique solo los campos necesarios.
4. Confirme los cambios.

!!! warning "INTEGRIDAD DEL HISTORIAL"
    No elimine un galpón que tenga registros asociados si necesita conservar el historial. El sistema puede rechazar la eliminación.

## Registrar producción diaria

1. Abra **Registros**.
2. Seleccione **Producción Diaria**.
3. Indique fecha, hora, semana y jornada.
4. Seleccione el galpón.
5. Registre huevos buenos, rotos y de descarte.
6. Agregue observaciones si son necesarias.
7. Haga clic en **Guardar**.

!!! warning "VALIDACIÓN"
    Las cantidades no deben ser negativas y deben corresponder al galpón y la jornada seleccionados.

## Clasificar huevos

1. Abra **Clasificación Huevos**.
2. Seleccione la producción correspondiente.
3. Registre las cantidades por tipo: A, AA, AAA, B, C o Jumbo.
4. Revise los totales.
5. Haga clic en **Guardar**.

## Registrar mortalidad

1. Abra **Mortalidad**.
2. Seleccione **Nuevo registro**.
3. Indique fecha, cantidad, edad en semanas y causa.
4. Registre necropsia y disposición final si aplica.
5. Seleccione el galpón.
6. Confirme.

Los registros deben representar hechos verificables y conservar la trazabilidad del responsable.

## Registrar morbilidad

1. Abra **Morbilidad**.
2. Cree el reporte con fecha y grado: leve, moderado o crítico.
3. Indique la cantidad de aves afectadas.
4. Describa los síntomas.
5. Agregue el concepto veterinario si está disponible.
6. Seleccione el galpón y guarde.

## Registrar tratamiento

1. Abra **Tratamiento**.
2. Cree el registro con fecha y diagnóstico.
3. Indique tratamiento, tipo, vía y dosis.
4. Registre duración y médico veterinario.
5. Indique el operario encargado.
6. Vincule la morbilidad correspondiente si existe.
7. Haga clic en **Guardar**.

!!! danger "DOSIS Y TIEMPOS"
    Verifique las dosis y los tiempos con el responsable veterinario antes de registrar o ejecutar el tratamiento.

## Registrar movimientos financieros

Esta función está disponible para usuarios administrativos.

1. Abra **Finanzas**.
2. Cree una operación.
3. Seleccione ingreso o gasto.
4. Indique fecha, concepto y monto.
5. Seleccione una categoría si corresponde.
6. Indique el estado: completado, pendiente o cancelado.
7. Haga clic en **Guardar**.

!!! warning "HISTORIAL FINANCIERO"
    No modifique ni elimine operaciones contables sin documentar el motivo. Consulte al administrador.

## Generar reportes

1. Abra **Reportes**.
2. Defina rango de fechas y otros filtros disponibles.
3. Seleccione el reporte.
4. Revise los totales y gráficos.
5. Exporte a Excel o PDF si la opción está disponible.

Si falta un dato, revise primero el registro operativo correspondiente.

## Consultar notificaciones

1. Abra **Notificaciones**.
2. Revise las alertas nuevas.
3. Seleccione una notificación para ver su detalle.
4. Márquela como leída si la opción está disponible.

## Trabajar sin conexión

AVISENA puede guardar temporalmente operaciones de escritura en el navegador cuando no puede comunicarse con el servidor.

1. Si pierde la conexión, conserve abierta la página.
2. Complete el registro normalmente si el formulario lo permite.
3. Espere a que vuelva la conexión.
4. Use la indicación de sincronización o recargue el sistema.
5. Verifique que el registro aparezca antes de cerrar la sesión.

!!! warning "NO BORRAR DATOS DEL NAVEGADOR"
    No borre el almacenamiento local ni use limpieza de datos mientras existan operaciones pendientes de sincronización.
