# Perfil y cuenta

## Consultar el perfil

1. Haga clic en el avatar ubicado en la parte superior derecha.
2. Seleccione **Mi Perfil**.
3. Revise los datos personales y la información de la granja.

## Cambiar contraseña

1. Abra el perfil o la configuración disponible para su cuenta.
2. Seleccione la opción **Cambiar contraseña**.
3. Confirme la contraseña actual.
4. Escriba y confirme la contraseña nueva.
5. Guarde los cambios.

La contraseña nueva debe tener al menos ocho caracteres.

## Gestionar usuarios

Esta opción está disponible para usuarios administradores.

### Crear un usuario

1. Abra **Gestión de Usuarios**.
2. Seleccione **Registrar usuario**.
3. Complete nombre, correo, celular, identificación, residencia y fecha de ingreso.
4. Asigne el rol correspondiente.
5. Configure la contraseña según el procedimiento disponible.
6. Haga clic en **Guardar**.

### Editar o inactivar un usuario

1. Localice el usuario en la tabla.
2. Seleccione la opción de edición.
3. Modifique únicamente los datos necesarios.
4. Guarde los cambios.

Para impedir el acceso, use el estado **Inactivo**.

!!! danger "SEGURIDAD DE CUENTAS"
    No comparta cuentas ni contraseñas. Si cambia el responsable de una tarea, actualice el usuario correspondiente.
