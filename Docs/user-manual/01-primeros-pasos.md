# Primeros pasos

## Iniciar sesión

1. Abra la dirección de AVISENA COL.
2. Seleccione o visite la ruta `/login`.
3. Escriba su correo electrónico o identificador disponible.
4. Escriba su contraseña.
5. Haga clic en **Iniciar sesión**.

Si los datos son correctos, el sistema abre la pantalla **Inicio**.

!!! warning "NOTA DE SEGURIDAD"
    Después de iniciar sesión, no use el botón atrás del navegador para volver a una sesión anterior.

## Recuperar la contraseña

1. En el inicio de sesión, seleccione **Olvidó su contraseña**.
2. Escriba el correo asociado a la cuenta.
3. Haga clic en la opción para solicitar el código.
4. Introduzca el código de seis dígitos recibido.
5. Cree una contraseña nueva y confírmela.

Después del restablecimiento, el sistema puede redirigir automáticamente al inicio de sesión.

!!! note "Si no recibe el código"
    Revise la carpeta de spam y confirme con el administrador que el correo esté configurado correctamente.

## Navegación

El menú lateral permite acceder a las funciones disponibles:

- **Inicio**
- **Gestión de Usuarios**
- **Galpones de aves**
- **Registros**
    - **Producción Diaria**
    - **Clasificación Huevos**
    - **Mortalidad**
    - **Morbilidad**
    - **Tratamiento**
- **Reportes**
- **Finanzas**
- **Notificaciones**
- **Asistente Avícola**

Las opciones pueden ocultarse según el rol. Desde el avatar puede abrir:

- **Mi Perfil**
- **Configuración**
- **Cerrar Sesión**
