# Manual de Usuario — AVISENA COL

Bienvenido al manual de usuario de **AVISENA COL**, una aplicación web para el registro y seguimiento de las operaciones de una unidad avícola.

| Campo | Información |
|---|---|
| Proyecto | AVISENA COL |
| Versión documental | v1.0.0 |
| Versión de aplicación | v0.1.0 |
| Audiencia | Administradores, instructores, aprendices, operarios e investigadores |
| Estado | Vigente |

## ¿Qué puede hacer en AVISENA?

- Consultar indicadores en el inicio.
- Gestionar usuarios si cuenta con el rol administrativo.
- Administrar galpones de aves y lotes.
- Registrar producción y clasificación de huevos.
- Registrar mortalidad, morbilidad y tratamientos.
- Consultar reportes.
- Registrar movimientos financieros si cuenta con permisos administrativos.
- Revisar notificaciones y usar el asistente avícola.

## Requisitos

- Navegador web actualizado.
- Conexión a Internet o a la red donde esté desplegado el sistema.
- Cuenta activa.
- Permisos asociados al rol.

## Roles

Las opciones disponibles pueden variar:

- **Administrador o Instructor Líder:** Acceso a gestión de usuarios y finanzas.
- **Aprendiz:** Acceso operativo según los permisos configurados.
- **Investigador:** Acceso según los permisos configurados.

!!! info "Uso seguro"
    No comparta su usuario ni su contraseña. Cierre la sesión al finalizar el trabajo.
